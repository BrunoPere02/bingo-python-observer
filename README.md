# 🎱 Bingo Python - Padrão Observer

Jogo de Bingo desenvolvido em Python utilizando o Padrão de Projeto Observer.

## 📋 Sobre o Projeto

Projeto acadêmico desenvolvido para a faculdade, aplicando o padrão de projeto **Observer** na comunicação entre o Sorteador e a Cartela do jogo.

## 🚀 Tecnologias Utilizadas

- **Python 3**
- **Padrão de Projeto Observer**
- **Orientação a Objetos**

## 🎮 Como Funciona

Sorteador (Subject) sorteia números aleatórios, notifica a Cartela (Observer) que marca os acertos. Quando a cartela está completa, o jogador vence!

## 🗂️ Estrutura do Projeto

| Classe | Responsabilidade |
|--------|-----------------|
| Sorteador | Sorteia números e notifica observadores |
| Cartela | Recebe números e verifica vitória |

## ▶️ Como Rodar

Execute no terminal: python bingo.py
